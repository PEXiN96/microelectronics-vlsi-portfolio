# CAD Design Report — SEL Circuit Using Cadence Virtuoso

## Overview

This project documents the design of an SEL circuit using Cadence Virtuoso as part of my academic studies in microelectronics and VLSI engineering.

The report presents the circuit design workflow, including schematic creation, symbol generation, and physical layout design.

## Objectives

- Create the SEL circuit schematic in Cadence Virtuoso.
- Generate a symbol representing the designed circuit for reuse in higher-level schematics.
- Develop the physical layout of the circuit.
- Document the design process and the corresponding results.

## Design Workflow

### 1. Schematic Design

The circuit schematic was created in Cadence Virtuoso by arranging and connecting the required circuit components according to the assigned design.

### 2. Symbol Creation

A symbol was generated from the schematic to represent the circuit as a reusable design block.

### 3. Layout Design

The physical layout of the circuit was developed in Cadence Virtuoso, following the design requirements specified in the laboratory assignment.

## Tools Used

- Cadence Virtuoso
- Schematic editor
- Symbol editor
- Layout editor
